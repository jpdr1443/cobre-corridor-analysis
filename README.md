# Cobre · Transaction Corridor Analysis

Solution to the **L2 Business Architect Assessment**: analysis of 50,000 cross-border payment transactions
(5,000 users, Jul–Dec 2025) across five corridors between the US, Mexico and Colombia.

## Headline
- **USD→MXN** is the largest corridor and the only one growing, but it fails about **4× more** than the rest and
  drives most of Cobre's failures.
- The failure belongs to the **corridor**, not to a customer type: every segment fails more, it worsens above
  **US$10K**, and the day of the week has no effect (the brief's Friday pattern does not hold in the data).
- Recommendation for 2026: **prioritize USD→MXN** — fix reliability first (recoverable revenue), then grow.

Exact figures are in the PDF and the notebook; every number is generated by the code.

## How it works
```
transactions.csv + users.csv
        │
        ▼
python/cobre  ──►  main.py            → result tables (outputs/Part1-3_*.xlsx) + findings_report.md
(one package)  ──►  build_excel.py     → outputs/Cobre_Dashboard.xlsx (values only, no formulas)
               ──►  build_document.py  → outputs/Cobre_Assessment_Deliverable.docx / .pdf
               ──►  notebooks/analysis.ipynb (imports the same package)
```
All text (answers, write-up, memo) lives in `python/cobre/answers.py` and all figures come from the analysis
modules, so the PDF, the Excel workbook and the notebook always show the same numbers.

## Reproduce
```bash
pip install -r python/requirements.txt
# place transactions.csv and users.csv in the repository root (not versioned)
cd python
python main.py && python build_excel.py && python build_document.py
```
